# Sahab-Video
صاحب فيديو هو تطبيق لمشاهدة ومشاركة مقاطع الفيديو القصيرة والطويلة، يجمع المستخدمين وصنّاع المحتوى في منصة واحدة. يتيح لك اكتشاف فيديوهات متنوعة، ومتابعة القنوات المفضلة، والإعجاب بالمقاطع والتفاعل معها من خلال التعليقات. كما يمكنك إنشاء قناتك الخاصة ورفع فيديوهاتك ومشاركتها مع الآخرين، وبناء جمهور يتابع .
